# Blog App

A modern blog application built with React and Appwrite.

## 🚀 About

Blog App is a web application for creating, managing, and reading blog posts.

The project is built with React on the frontend and Appwrite for backend services such as authentication, database, and storage.

## 🛠️ Tech Stack

- React
- Vite
- Appwrite
- Redux Toolkit
- React Router
- JavaScript
- CSS
